Import a dataset

Each row must include a zone, category, valid latitude/longitude coordinates and date/time. ISO date-only values (YYYY-MM-DD) stay date-only; ISO date-times with an offset are exact. A date-time without an offset is interpreted as UTC. Severity is optional; when omitted, it defaults to 1.

Map your columns

Select the source column for each field. Zone names from your file are kept as separate analysis zones.

Importing changes the live dashboard only. The canonical 1,567-record synthetic research experiment and its saved results remain unchanged. The demo community-report form is disabled while an imported dataset is active.
